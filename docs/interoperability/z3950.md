# Z39.50 Client Implementation

## Overview

Real Z39.50 client using YAZ (YAZ 5.34.0) via CLI tools (`yaz-client`, `yaz-marcdump`) in Docker deployment.

## Architecture

- **Approach**: yaz-client CLI invoked via `execFile` with argument arrays (no shell concatenation)
- **Record capture**: `yaz-client -f cmds.txt -m recs.mrc` captures raw ISO2709 records
- **Conversion**: `yaz-marcdump -o json recs.mrc` converts to structured JSON
- **Parsing**: TypeScript parser converts JSON to catalogue fields
- **SSRF protection**: Trusted-target model with private IP blocking
